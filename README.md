# YChess

A full-stack chess platform with AI opponent, AI coaching, real-time multiplayer, Meme Mode, and replayable game history.

**Live:** [ychess.me](https://ychess.me)

---

## Features

### Core Chess
- Full legal-move validation (castling, en passant, promotion, stalemate, 50-move rule)
- Move hints, last-move highlight, king-in-check glow
- Drag-and-drop pieces with animations and Web Audio sound effects
- Board coordinates, 5 board themes, 3 purchasable piece skins (Neon / Gold / Crystal)
- Move history navigation — click any move or use ← → arrow keys to step through the game
- Pawn promotion dialog

### Game Modes
- **Player vs Player** — local two-player on the same device
- **Player vs AI** — pure JS minimax with alpha-beta pruning, adjustable difficulty 1–20 (maps to search depth 1–4). Runs entirely in-browser — no server calls, instant moves
- **Multiplayer** — create a room, share the link, play live with a friend. Real-time sync via Appwrite Realtime. Supports chess clocks (1 / 3 / 5 / 10 min), board flip for Black, drag-and-drop

### AI Features
- **AI Coach** — ask for advice on any position; streams a response from Llama 3.3 70B (Groq)
- **Post-Game Analysis** — after checkmate or draw, get a full blunder review streamed from the same model
- **Chess Clock** — Off / 1m / 3m / 5m / 10m; active player highlighted; timeout declares a winner automatically

### Meme Mode 💀
Toggle **Meme Mode** from the action buttons on the main board. While active:

- The page background changes to a full-cover meme wallpaper
- After every move (yours and the AI's) a short Gen Z / TikTok-style reaction is generated by Llama 3.3 70B — contextual to what actually happened (en passant, queen captures, checkmate, castling, etc.)
- Real meme sounds play from a curated library of 22 tracks downloaded from myinstants.com, distributed by situation:

| Situation | Sounds |
|---|---|
| Regular move | Instagram Thud, Punch, Wow Anime, Bruh, Oi Oi Oe |
| Capture | AUUGHH, What The Hell, Oh My God, Emotional Damage, FAAHH, Shocked |
| Queen captured | Baby Laugh, Cat Laugh, Rizzbot Laugh, Oh My God, Emotional Damage |
| Check | −999 Social Credit, Among Us, What The Hell, Emotional Damage |
| En passant | Galaxy Meme, −999 Social Credit, Among Us, What The Hell |
| Win | French Meme Song, Spiderman Meme, Oi Oi Oe, Baby Laugh, Rizzbot, Cat Laugh |
| Loss | Snore Mimimimi, Bruh, Dexter Meme, Bing Chilling, Galaxy |

- Each new move stops the previous sound before playing the next
- All sounds are preloaded the moment Meme Mode is turned on
- Toggle off to restore the normal board and sounds instantly

### Auth
- **Email / Password** registration and login via Appwrite
- **Google OAuth** — one-click sign-in with Google. Implemented via Appwrite's OAuth2 provider; no extra backend code needed

To enable Google OAuth in your own deployment:
1. Create OAuth 2.0 credentials in [Google Cloud Console](https://console.cloud.google.com) (Web application type)
2. Add this redirect URI: `https://fra.cloud.appwrite.io/v1/account/sessions/oauth2/callback/google/<YOUR_PROJECT_ID>`
3. In Appwrite Console → Auth → Settings → OAuth2 Providers → Google: paste the App ID (Client ID) and App Secret (Client Secret)
4. In Appwrite → Settings → Platforms: add your domain as a Web platform

### Profile & Leaderboard
- Per-user stats: wins, losses, draws, win rate
- Full game history with replay links
- Global leaderboard ranked by wins

## Getting Started

### 1. Clone

```bash
git clone https://github.com/yerkonty/Chess_nfactorial.git
cd Chess_nfactorial/client
npm install
```

### 2. Environment variables

Create `client/.env.local`:

```env
NEXT_PUBLIC_APPWRITE_ENDPOINT="https://fra.cloud.appwrite.io/v1"
NEXT_PUBLIC_APPWRITE_PROJECT_ID="your-appwrite-project-id"
NEXT_PUBLIC_APPWRITE_DATABASE_ID="your-database-id"
NEXT_PUBLIC_APPWRITE_GAMES_COLLECTION_ID="games"
GROQ_API_KEY="your-groq-api-key"
STRIPE_SECRET_KEY="your-stripe-secret-key"        # optional
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY="pk_..."        # optional
```

### 3. Appwrite setup

1. Create a project at [appwrite.io](https://appwrite.io)
2. Enable **Email/Password** and **Google OAuth** authentication (see Auth section above for Google setup)
3. Add your domain in Settings → Platforms (add `localhost` for dev)
4. Create a database with two collections:

**games**
| Attribute | Type |
|---|---|
| userId | string |
| userName | string |
| result | string |
| mode | string |
| pgn | string |

**rooms** (multiplayer)
| Attribute | Type |
|---|---|
| fen | string |
| pgn | string (optional) |
| status | string (`waiting` / `active` / `finished`) |
| player1Id | string |
| player1Name | string |
| player2Id | string (optional) |
| player2Name | string (optional) |
| turn | string |
| lastMove | string (optional) |
| whiteTime | number (optional) |
| blackTime | number (optional) |
| timerDuration | number (optional) |
| lastMoveAt | datetime (optional) |
| result | string (optional) |

### 4. Groq API key

Sign up at [console.groq.com](https://console.groq.com) and create a key. Used for the AI Coach, Post-Game Analysis, and Meme Mode reactions.

### 5. Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

1. Push to GitHub
2. Import the `client/` directory in [Vercel](https://vercel.com)
3. Add the environment variables from `.env.local`
4. Deploy — auto-deploys on every push to `main`
